# 界舟 · Harness Dock identity

Approved identity, applied to the client source, packaging and documentation site. Updating source does not publish a release or replace an installed app.

- `jiezhou.svg`: approved transparent vector master, 界舟 / Jiezhou.
- `jiezhou-concept.svg`: Chinese wordmark, hutian family comparison and size previews.
- `harness-dock.svg`: transparent vector master, 512 × 512 viewBox.
- `concept.svg`: presentation with light, dark, monochrome and small-size previews.

## 界舟 / Jiezhou

界舟 is a newly coined brand name, not the name of a historical mythical
artifact. The angular vessel evokes travel between independent environments;
the central notch in the hull evokes docking. The separate geometric sails
give the mark a recognizable boat silhouette. These are brand metaphors, not
a network topology or a claim that execution moves between devices.

The mark shares hutian's emerald and 45-degree geometry. The transparent SVG
uses three filled paths. The concept sheet pairs the mark with the existing
hutian artwork already present in this repository. It uses system fonts for
the wordmark; no font files are bundled. The brand is displayed as 界舟 / Jiezhou, alongside the technical name Harness
Dock. Repository names, SDK contracts, bundle identity, app bundle filename,
URL scheme and existing credentials retain their technical identifiers.

## Earlier H concept

The second concept uses two facing docking brackets joined by a central bridge
to represent cross-device access. Together they form an H for Harness. The
square proportions, mirrored geometry and centered visual weight replace the
first concept's protruding port. These are brand metaphors, not a network
topology or an execution-state indicator.

The design follows hutian's emerald color (`#00C89B`), heavy geometric forms
and 45-degree cuts. The master uses one filled path, with no fonts, external
resources, gradients or filters. For monochrome use, replace the group fill.

Suggested minimum displayed size: 24 px. The 16 px preview is exploratory;
a dedicated optically adjusted favicon should precede production adoption.
