# 资源管理

Daemon 持有 Provider 进程、待批请求和执行状态；连接关闭不改变执行所有权。原生 home、用户配置、认证、插件、memory 和工作目录不属于 dock 的清理范围。

## 默认限制

| 资源 | 限制与行为 |
| --- | --- |
| 每连接待响应请求 / 并行入站处理 | 32 / 16；超额拒绝或关闭连接 |
| 单条消息、累计入站或发送占用 | 各 64 MiB；包含尚未结束的处理 |
| 本地发送 deadline | 60 秒；写回调不等于对端或原生 ACK |
| 设备并行执行 | 默认 2，可配置 1..8；相同原生会话互斥 |
| Provider 空闲回收 | 默认 10 分钟；活动执行和审批等待不回收 |
| 单轮文本 | 8 MiB UTF-8 |
| 单条展示观察 | 256 KiB；超限显式报告 |
| 单轮持久化过程 | 32 MiB / 10,000 条；截断单独标记 |
| 输入文件 | 每文件 8 MiB、合计 16 MiB、最多 64 个 |
| 已结束且已 release 的详细记录 | 保留 7 天；去重身份继续保留 |
| SQLite 与托管状态目录 | 软预算 512 MiB；回收后仍超限则停止新准入 |
| 执行身份数量 | 100,000；达到上限停止新身份准入 |
| Daemon 日志 | 3 个 10 MiB 文件，滚动保留 |

这些是 dock 管理资源的预算，不是 Provider 进程内存、用户工作目录或 OS 磁盘硬配额。JSON/Base64 等编码还会产生额外占用。

## 生命周期

prepare/execute 检查托管状态和容量，不跨阶段复用过期统计。执行、探测、关闭和维护使用各自的准入与互斥边界；等待审批仍为活动执行。

连接换代不会重置尚未结束的入站处理预算。过载断开后只恢复连接与观察，不重派执行、工具或审批。调用方 callback 必须响应 AbortSignal，迟到决定不进入下一轮。

release 仅删除已确认结束的本轮托管输出，unknown 拒绝释放。forgetSession 只在相关执行安全释放后删除托管会话，保留执行去重身份和用户文件。

程序升级、回滚、server 撤销配对都不删除原生 home 或用户数据，也不把 unknown 自动改成成功或取消。磁盘或存储故障时保留已落盘执行身份，重启后按 unknown 查询，不能靠清库恢复新准入。

## 托管文件

文件操作限制在准备的目录内，拒绝越界和不受信任的符号链接。输出 collect 返回内容、文件名和 SHA256。调用方应先验收并收存输出，再 release。

状态读取可能返回 detailsExpired 或 historyTruncated，表示详情过期或观察截断；这些字段不改变技术终态。安装和恢复要求见 [设备维护](device.md) 与 [SDK](sdk.md)。
